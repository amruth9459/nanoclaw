# NanoClaw Security + Reliability Audit — 2026-07-12

Full-codebase audit of the live daemon (PID at time: 9920). Two parallel audits:
security (untrusted WhatsApp→IPC→host command surface) and reliability (the
message loop / scheduler / container lifecycle). Findings below; fixes tracked
in the "Status" column as they land.

**S1 detail:** any member of any registered group sends an image/video whose
protobuf `mimetype` is `image/x";touch /tmp/pwned;#`. `extension =
mimetype.split('/')[1]` is unsanitized, flows into
`execSync(\`sips … "${filePath}"\`)`. No @-trigger, no agent — fires in
`downloadAndSaveMedia` for every media message. Video path (ffprobe/ffmpeg) is
not darwin-gated. Fix: `execFileSync` with argv arrays + whitelist extension to
`[a-z0-9]{1,5}`.

**S2 detail:** document `fileName` → `extension = fileName.split('.').pop()`
unsanitized → `path.join(MEDIA_DIR, \`${id}.${extension}\`)` collapses `../` →
`fs.writeFileSync` overwrites e.g. `groups/main/CLAUDE.md` (persistent prompt
injection) with attacker bytes. Fix: strip extension to `[a-z0-9]` + assert
resolved path within MEDIA_DIR.

**S3/S4 detail:** `toHostWorkspacePath` / `toHostIpcPath` `path.join` container
paths without a containment check; a prompt-injected agent emits
`filePath:"/workspace/group/../../.env"` or an absolute `responseFile`. Fix:
`assertWithinBase(resolved, base)` after join; never use the container path
verbatim.

## New feature (same session)

**cmux bridge** — `cmux_sessions` MCP tool (main group only) lets the WhatsApp
agent list/read/drive the user's cmux coding sessions. Host module
`src/cmux-bridge.ts` (execFile argv, no shell; workspace-ref whitelist; isMain
gate in `ipc.ts`). IPC round-trip verified end-to-end through the live daemon;
`list`/`read` verified returning live session data. cmux's socket defaults to
`socketControlMode: "cmuxOnly"` (cmux-descendants only), so the background
launchd daemon needs password-mode enabled to drive it — see docs/CMUX_BRIDGE.md.
Works immediately when NanoClaw runs inside a cmux tab.
